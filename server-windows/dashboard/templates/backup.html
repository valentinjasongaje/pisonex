Backup & Restore

A backup saves everything: members and their time balances, PCs and the time left on them, sessions, sales, coin rates, settings and staff accounts.

A backup is made automatically once a day (the newest {{ keep }} are kept). Download one regularly and keep it off this machine — on a USB stick or in Google Drive — so a broken disk or an uninstall can never lose the café's data. Each file also contains members.csv and active_sessions.csv, which open in Excel. Stored on this server in {{ backup_dir }}.
